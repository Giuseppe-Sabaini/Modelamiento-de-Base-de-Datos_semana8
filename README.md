# Script de Base de Datos Oracle SQL
Este proyecto contiene un script en Oracle SQL para crear y gestionar una base de datos de Taller Mecánico Mikes Ltda, permite gestionar Mecanico, Mantencion,
Sucursal, Servicio, Ciudad, Pais, y los impuestos a los trabajadores.
